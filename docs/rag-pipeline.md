# RAG Pipeline

PDF upload stores the original file under a generated filename. PDFBox extracts text page by page so page metadata can be retained. Text is split into overlapping chunks. Each chunk is wrapped as a Spring AI `Document` with `documentId`, `filename`, `page`, and `chunkId` metadata, then persisted through the pgvector vector store.

Question answering performs semantic similarity retrieval with configurable top-K and threshold values. If no chunks are retrieved, the backend returns a grounded false fallback without asking the LLM to invent an answer. Citations are generated by the backend from retrieved chunk metadata, not fabricated by the model.
